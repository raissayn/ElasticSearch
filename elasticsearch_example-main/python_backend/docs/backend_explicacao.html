Conversao do Backend Java para Python

O objetivo foi manter a mesma ideia do backend Java em uma nova pasta Python, para facilitar comparacao e estudo.

Ideia do backend

A API recebe uma consulta no endpoint GET /v1/search, envia essa consulta ao Elasticsearch, pega os documentos encontrados no indice wikipedia e devolve uma lista com title, url e abs.

Estrutura de pastas

python_backend/
  app/
    main.py
    controllers/search_controller.py
    services/search_service.py
    domain/es_client.py
    schemas/result.py
    core/config.py
  tests/
  docs/backend_explicacao.html

Explicacao de cada arquivo

main.py cria a aplicacao FastAPI.

search_controller.py define a rota HTTP.

search_service.py concentra a regra de negocio e a limpeza do texto.

es_client.py faz a conexao com o Elasticsearch e monta a busca.

result.py define o formato da resposta.

config.py guarda as configuracoes centrais do backend.

Fluxo da requisicao

  1. O usuario chama /v1/search?query=...&page=....
  2. O controller recebe os parametros.
  3. O service chama o cliente do Elasticsearch.
  4. O cliente busca no indice wikipedia usando o campo content.
  5. O service limpa o conteudo e monta os objetos finais.
  6. A API devolve uma lista JSON.

Como a limpeza funciona

O metodo treat_content remove tags como <som1> e <math3>, tira caracteres especiais e normaliza os espacos. Isso segue a mesma ideia do backend Java.

Como executar

cd python_backend
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8080

Depois, acesse http://127.0.0.1:8080/docs para ver a documentacao automatica do FastAPI.
